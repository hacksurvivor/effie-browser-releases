# Effie Browser releases

Downloads and the update feed for Effie Browser for Mac.

- **Download:** the latest release's `Effie-Browser-<version>.zip`. Unzip it and move Effie Browser to Applications.
- **Updates:** Effie Browser checks `appcast.json` on the latest release and offers new versions itself.

Every build is signed with a Developer ID and notarized by Apple. It needs an Apple silicon Mac.
